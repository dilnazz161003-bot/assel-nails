# Асель — nail studio

Одностраничный сайт с онлайн-записью к нейл-мастеру (Уральск, ТД «Астана 2», 2 этаж, бутик 11).
Чистые HTML/CSS/JS без сборки и зависимостей — достаточно открыть `index.html` или выложить папку на любой статический хостинг (GitHub Pages, Netlify).

## Что настроить перед запуском

Всё редактируемое собрано в `js/data.js`:

- `CONFIG.whatsapp` — номер WhatsApp мастера, только цифры (`77028864446`); `CONFIG.phone` — он же для показа.
- `CONFIG.workDays`, `openHour`, `closeHour` — график работы.
- `CONFIG.bookedSlots` — вручную занятые слоты.
- `CONFIG.demoBusy` — демо-занятость слотов. **Поставьте `false`**, чтобы клиенты видели всё рабочее время свободным.
- `CATEGORIES`, `SERVICES`, `PRICE_DATE` — прайс по разделам: цены (₸) и ориентировочная длительность.
- `PORTFOLIO`, `SHADES`, `REVIEWS` — портфолио, подборки оттенков, отзывы.

Тексты интерфейса на русском и казахском — в `js/i18n.js`.

## Структура

```
index.html      разметка всех секций
css/style.css   стили (mobile-first, планшет ≥720px, десктоп ≥1080px)
js/i18n.js      словари RU / KZ
js/data.js      настройки и контент
js/app.js       логика: язык, меню, портфолио, подбор оттенка, форма записи
```

Заявка из формы не уходит на сервер: на последнем шаге открывается WhatsApp с готовым текстом, мастер подтверждает время в ответ.
